UG Voice Control

Go to ultimate-guitar.com to use the voice extension.

Click the 🎤 icon in the bottom right to start listening.

Commands (say "Rockstar" first to wake it up):

  • "Rockstar search for [song]" / "Rockstar cherche [chanson]"
  • "Rockstar search playlist [song]" / "Rockstar cherche dans ma playlist [chanson]"
  • "Rockstar scroll down" / "Rockstar descend"
  • "Rockstar scroll up" / "Rockstar monte"
  • "Rockstar pause" (to pause scrolling)
  • "Rockstar go to top" / "Rockstar début"
  • "Rockstar faster" / "Rockstar plus vite"
  • "Rockstar slower" / "Rockstar moins vite"
  • "Rockstar stop" / "Rockstar dors" (to put it to sleep)
