Vox Roddy

Allez sur votre site de tablatures pour utiliser les commandes vocales.

Cliquez sur le bouton micro en bas à droite pour démarrer.

Commandes (dites "Roddy" en premier pour réveiller) :

  • "Roddy search for [song]" / "Roddy cherche [chanson]"
  • "Roddy search playlist [song]" / "Roddy cherche dans ma playlist [chanson]"
  • "Roddy scroll down" / "Roddy défile"
  • "Roddy descends un peu / beaucoup"
  • "Roddy monte / remonte un peu / beaucoup"
  • "Roddy pause" (suspendre)
  • "Roddy go to top" / "Roddy début"
  • "Roddy faster" / "Roddy plus vite"
  • "Roddy slower" / "Roddy moins vite"
  • "Roddy stop" / "Roddy dors" (veille)

Contrôles Vidéo (YouTube) :

  • "play" / "lecture" / "joue"
  • "pause" / "stop"
  • "recule [de X secondes]"
  • "avance [de X secondes]"
  • "recommence" (remet au début)
  • "vitesse [0.25 - 4.0]"
  • "vitesse normale"
  • "enregistre repère [nom]"
  • "retourne au repère [nom]"

Métronome :

  • "démarre le métronome" / "metronome play"
  • "arrête le métronome" / "metronome stop"
  • "tempo [40 - 240]" (ex: "tempo 120")
  • "mesure [4/4, 3/4, 2/4, 6/8, 1/4]" (ex: "mesure 3 4")
  • "son [bois, digital, tambour]" (ex: "son tambour")
  • "volume [0 - 100]" (ex: "volume 70")

Saisissez le mot à prononcer avant chaque commande.

Variantes similaires captées par le micro qui déclencheront aussi Vox Roddy.

Ferme le microphone en cas d'inactivité.
