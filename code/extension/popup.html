Rockstar Companion

Allez sur votre site de tablatures pour utiliser les commandes vocales.

Cliquez sur l'icône 🎤 en bas à droite pour démarrer.

Commandes (dites "Rockstar" en premier pour réveiller) :

  • "Rockstar search for [song]" / "Rockstar cherche [chanson]"
  • "Rockstar search playlist [song]" / "Rockstar cherche dans ma playlist [chanson]"
  • "Rockstar scroll down" / "Rockstar défile"
  • "Rockstar scroll up" / "Rockstar monte"
  • "Rockstar pause" (suspendre)
  • "Rockstar go to top" / "Rockstar début"
  • "Rockstar faster" / "Rockstar plus vite"
  • "Rockstar slower" / "Rockstar moins vite"
  • "Rockstar stop" / "Rockstar dors" (veille)

Saisissez le mot à prononcer avant chaque commande.
